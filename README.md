# Functional Analysis Lab

An interactive English study guide for functional analysis: precise theorem statements, rendered LaTeX, worked examples, problem-solving recipes, and practice questions.

The site is static. Open `index.html` locally or visit the GitHub Pages site once deployment is enabled.

The six lecture documents used to prepare the lessons are referenced in the Lecture map. Their original PDF files are not part of this public repository.

Mathematics is rendered with [KaTeX](https://katex.org/); the bundled KaTeX license is in `vendor/katex/LICENSE`.
